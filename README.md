# Retasc docs

Source for **[docs.retasc.com](https://docs.retasc.com)** — onboarding, how the queue
behaves, pricing, and the generated CLI/MCP reference. Built on [Mintlify](https://mintlify.com),
which deploys this repo on every push to `main`.

## The rule that matters

**Most of what is in here is generated from the Retasc monorepo, and editing it by hand is a
bug.** The reference tables, the screenshots, the OG cards, the logo and the favicon all have
a generator; a hand edit survives until the next release and then silently reverts. The
generated regions are fenced with `{/* docs-facts:… */}` markers so the scripts can find them
and so a reviewer can see where the boundary is.

| What | Generated by (in the Retasc monorepo) |
|------|----------------------------------------|
| `cli.mdx` command table, `mcp-tools.mdx` tool table and prices | `scripts/docs-facts.py` — reads `convex/http.ts`, `operations/pricing.md` and `retasc --help` |
| `changelog.mdx` | `scripts/build-changelog-page` (run by `scripts/lib/changelog-page.sh` on a CLI release) |
| `images/og/*.png` | `scripts/docs-facts.py` → the shared card generator; one card per page, headline read from the page's own `<h1>` |
| `images/ui/*-{dark,light}[-phone].png` | `scripts/docs-shots.py` — real Dash screens captured from the `?dev=1` fixtures, never redrawn; four cuts each, two palettes by two widths, because the Dash draws itself differently on a phone |
| `icons/*.svg` | `scripts/docs-icons.py` — Radix Icons, fetched from source and repointed |
| `logo/{dark,light}.svg`, `favicon.svg` | `scripts/gen-icons.py` — the same mark the landing and the Dash use |

Everything else — page prose, `docs.json`, `style.css` — is written here by hand.

## Styling: the design system on someone else's shell

`style.css` is the canon in `operations/design-system.md` — the two palettes, the token set,
the type steps, mono as the system voice — applied to a page shell this repo does not own.
Three consequences are structural, not sloppiness, and each is commented at its rule:

- **Overrides carry `!important`.** Mintlify ships Tailwind utilities in its own markup; a
  token can only win against a utility class at the same or higher weight.
- **Light/dark image pairs use our own `rt-shot-light` / `rt-shot-dark` classes.** Mintlify's
  Tailwind build does not scan MDX, so `dark:hidden` written in a page compiles to nothing
  and both cuts render at once.
- **Local SVG icons render as `<img>`, so they cannot inherit `currentColor`.** They are
  drawn in the ink they need and, where a state demands the other palette, inverted.

## The gate

Screenshots are not an audit. `operations/audits/docsaudit.py` in the monorepo renders every
page across six widths in both palettes and fails on overflow, invisible or blank text,
duplicated controls, split controls, foreign colours, broken vertical rhythm, both image cuts
showing at once, and a scrollbar that is not on `--dim`. Run it against a running preview
before pushing:

```bash
python3 ../retasc/operations/audits/docsaudit.py http://localhost:3333
python3 ../retasc/operations/audits/docsaudit.py --page /pricing --width 390   # one cell, while iterating
```

The full matrix holds a browser and the Mintlify preview in memory at once; narrow it with
`--page` / `--width` during a fix and run it whole before pushing.
