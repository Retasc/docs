| Source | You pick a… | Identifiers | Token from |
|---|---|---|---|
| **Linear** | team | kept (`TEAM-N`) | Settings → Security & access → Personal API keys |
| **Jira** (Cloud only) | project | kept (`PROJ-42`) | id.atlassian.com → Security → API tokens |
| **ClickUp** | list | renumbered `PREFIX-N` | Settings → Apps → API Token |
| **Asana** | project | renumbered `PREFIX-N` | Settings → Apps → Developer → Personal access tokens |
| **Shortcut** | team | story numbers kept | Settings → API Tokens |

## Set up

<Steps>
  <Step title="Pick the source">
    **Connectors → Migrate**, then the source's card.
  </Step>

  <Step title="Paste the token">
    Used live for this run only, never stored. Jira also asks for the site
    (`your-domain.atlassian.net`) and account email.
  </Step>

  <Step title="Fetch targets, pick one">
    The team, project, or list to bring across.
  </Step>

  <Step title="Say what your columns mean">
    Jira, ClickUp, and Asana surface each source column to map to `todo` / `doing` /
    `review` / `done` / `canceled`, pre-filled from the column's *type*, never its
    name. A column mapped to `review` needs a named reviewer. Linear and Shortcut type
    their own columns, so they skip this step.
  </Step>

  <Step title="Import">
    Live progress, then a summary: created, updated, comments, links, files.
  </Step>

  <Step title="Claim your history">
    Imported authors arrive as placeholder members. Each real person clicks "That's
    me" once, and their authorship *and* their assigned backlog move onto their live
    account.
  </Step>
</Steps>

<Warning>
  **Re-importing overwrites your Retasc edits.** A second run never duplicates; it
  re-syncs, so status, labels, title and body snap back to whatever the source says
  now. Two weeks of moving issues along in Retasc can vanish. You are warned, with the
  date of the last import, before it runs.
</Warning>

<Note>
  **Same flow in the terminal:** `retasc import` walks the identical steps (source,
  token typed with echo off and never a flag, target, column mapping, import) and ends
  on the same identity-claim prompt.
</Note>
