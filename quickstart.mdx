One command signs you in, names your workspace and wires the agents on this machine.
Run it in the folder your agent works in:

```bash
npx @retasc/cli@latest bind
```

<Note>
  **Invited to an existing team?** Run `npx @retasc/cli@latest join <link>` with the
  invite instead. `bind` would create a second org. See
  [Onboarding: joining a team](/onboarding-member).
</Note>

<Steps>
  <Step title="Sign in">
    A browser opens. GitHub or Google, and you approve once.

    No browser on this machine (SSH, CI)? Mint a key on a machine with one and set
    `RETASC_MCP_KEY`. The command tells you so and stops.
  </Step>

  <Step title="Name the workspace">
    Org, first project, issue prefix. Most arrive pre-filled from the folder name. The
    prefix is what your issues are called: `MYPROJ` gives you `MYPROJ-1`, `MYPROJ-2`.

    ```
    ✓ Created org (my-org).
    ✓ Created project MYPROJ.
    ✓ Bound this folder to my-org / MYPROJ.
    ```
  </Step>

  <Step title="It wires your agent">
    Claude Code, Codex, Cursor, Grok, OpenCode and Gemini CLI, wherever it finds them on
    this machine. VS Code takes the address by hand: `https://mcp.retasc.com/mcp`.
  </Step>

  <Step title="Restart your agent">
    MCP config is read when the agent starts, so start it in this folder, or restart it
    if it is already open. Then check identity from inside the agent:

    ```
    whoami → org "my-org" / project MYPROJ
    ```

    And pull the first issue:

    ```
    next_issue → the top unblocked issue, claimed and leased to you
    ```
  </Step>
</Steps>

## Two other doors

**From your agent, with no terminal.** Paste this to the agent in your app. It installs
the Retasc skill, and the skill walks you through the rest:

```
Set Retasc up for me. First install the Retasc skill: npx skills add Retasc/skills -g
```

**From the terminal, without a browser step for each folder.** Install the CLI, sign in
once, then create the org and project in one shot:

```bash
npm install -g @retasc/cli
retasc login
cd /path/to/your-repo
retasc init --org "My Org" --project "My Project" --prefix MYPROJ
```

`init` is `bind` for a brand-new org. Everything after it is the same: restart the
agent, `whoami`, `next_issue`.

## What about billing?

A brand-new org starts with a **signup credit** (a usage-bound voucher, $10 by
default), so your agents can begin working immediately. Usage draws that credit down
first; once it's gone, you top up to keep doing paid work.

Buy credit anytime from the [Dashboard](https://dash.retasc.com) → **Billing**
→ **Buy credit**. See [Pricing](/pricing) for exactly what's metered and what it costs.

<Tip>
  Reads are always free, even at a zero balance, so an agent can always inspect its
  queue and tell you what it needs. Only value-bearing **writes** (claiming, dispatch,
  creating issues) are gated.
</Tip>

## Useful checks

| Command | What it tells you |
|---|---|
| `retasc whoami` | Which org/project this folder is bound to, and who you are |
| `retasc doctor` | Whether the binding, key, and MCP wiring are healthy |
