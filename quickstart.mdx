The fastest path, terminal only. If you want the full picture, or you're setting
someone up who'd rather click than type, see one of the onboarding guides instead:
this page is the fast path.

<Note>
  **Invited to an existing team?** Don't run `retasc init`, it creates a new org. See
  [Onboarding: joining a team](/onboarding-member) instead.
</Note>

<Steps>
  <Step title="Install the CLI">
    ```bash
    npm install -g @retasc/cli
    ```

    The binary is `retasc`. Check it:

    ```bash
    retasc --version
    ```
  </Step>

  <Step title="Sign in with GitHub">
    ```bash
    retasc login
    ```

    You'll see a device code to enter at GitHub:

    ```
      Open: https://github.com/login/device
      Enter code: XXXX-XXXX

      Waiting for authorization…
    ```

    Once authorized:

    ```
    ✓ Signed in as Ada Lovelace <ada@example.com>.
    ```
  </Step>

  <Step title="Create everything, in your project folder">
    From the repo (or working folder) your agents will run in:

    ```bash
    cd /path/to/your-repo
    retasc init --org "My Org" --project "My Project" --prefix MYPROJ
    ```

    This creates the org and project, mints an org-scoped API key, and wires the MCP
    server into this folder:

    ```
    ✓ Created org (my-org).
    ✓ Created project MYPROJ.
    ✓ Minted API key (retasc_b9737af…).
    ✓ Registered Retasc with the liveness watchdog (stdio proxy, scope: local).
    ```

    <Note>
      `--prefix` is your issue prefix (2 to 10 chars, A-Z/0-9, letter-first). For
      example, `MYPROJ` gives you `MYPROJ-1`, `MYPROJ-2`, and so on.
    </Note>
  </Step>

  <Step title="Restart your agent">
    Restart it (or its MCP client) so it picks up the new `retasc` MCP server. Verify
    identity from inside the agent:

    ```
    whoami → org "My Org" / project MYPROJ
    ```

    Then pull your first issue:

    ```
    next_issue → the top unblocked issue, claimed and leased to you
    ```
  </Step>
</Steps>

## What about billing?

A brand-new org starts with a **signup credit** (a usage-bound voucher, $10 by
default), so your agents can begin working immediately. Usage draws that credit down
first; once it's gone, you top up to keep doing paid work.

Buy credit anytime from the [Dashboard](https://dash.retasc.com) → **Billing**
→ **Buy credit**. See [Pricing](/pricing) for exactly what's metered and what it costs.

<Tip>
  Reads are always free, even at a zero balance, so an agent can always inspect its
  queue and tell you what it needs. Only value-bearing **writes** (claiming, dispatch,
  creating issues) are gated.
</Tip>

## Useful checks

| Command | What it tells you |
|---|---|
| `retasc whoami` | Which org/project this folder is bound to, and who you are |
| `retasc doctor` | Whether the binding, key, and MCP wiring are healthy |
